# 证据资产：为什么评测模型呈现这样的 BOH/ROH 行为（因果机制，论文原文核实）

> 把"ROH>BOH + VQA↔grounding 解耦"从现象升级为**有论文原文支撑的因果机制**。
> 核心论点（项目负责人提出）：极端幻觉 = 正样本-only RL 的必然副产物。**11 篇评测模型论文精读已证实。**

## 论点 1：正样本-only RL → 系统性"必画框"tradeoff（被论文原文证实）

**机制**：RL grounding 模型训练数据几乎全是正样本（目标必然存在、请定位），奖励=bbox/mask IoU，
从不惩罚"给不存在目标画框"，格式奖励强制 answer 槽必出框、无拒答动作 → 策略收敛到"无条件画框"，FG@Neg 飙高。

**关键自然实验：Visual-RFT 是唯一反例，正好证实因果方向。**
Visual-RFT（2503.01785）是六个 grounding 模型里**唯一**：
- 训练含负样本处理——检测提示明确 `If no object ... return "No Objects"`（Table 1），存在性前置判别（§4.1/§4.5）；
- 奖励**惩罚**自信的错框——置信奖励 `IoU=0 时 r=1−c`（式7），画幻觉框的置信越高罚越重；
- 有真正的弃权路径（"No Objects" 输出）。
→ **它的 FG@Neg 最低（28.2%）**。而纯正样本/纯 IoU/必出框的模型是极端幻觉端。

**跨 6 模型的剂量-反应谱系（FG@Neg 与"负样本处理程度"单调对应）：**
| 模型 | 负样本/拒答处理 | 奖励惩罚错框？ | FG@Neg |
|---|---|---|---|
| UniVG-R1 | 无，必出单框（§3.3 格式强制） | 否（纯 IoU） | 99.8% |
| Seg-zero | 无，提示"找最匹配对象"（Fig.4） | 否（二值 IoU>0.5） | 97.1% |
| LENS | 无，架构设计"必出 mask"（Fig.A5） | 否（IoU+seg-IoU） | 94.2% |
| VisionReasoner | 部分（gRefCOCO 变数量）+ max{N,K} 稀释罚 | 弱（数量归一化） | 80.8% |
| Seg-R1 | 前景存在性范式 + 训练见过"空掩码"退化解 | 隐式（S-measure） | 61.8% |
| **Visual-RFT** | **有 "No Objects" + 存在前置** | **有（置信罚，式7）** | **28.2%** |

**这是训练范式层面的干净 tradeoff**：Seg-zero mIoU 最高(0.52) / FG@Neg 也最高(97%)——正样本 IoU 刷得越狠，负样本拒答塌得越彻底。V-SIGHT 存在的理由由此坐实：这些模型的高 IoU 是牺牲拒答换来的，需要即插即用 verifier 把被 RL 训没的拒答能力补回来。

## 论点 2：判别与坐标回归不共享梯度 → VQA↔grounding 解耦（论文原文证实）

**结构前提**：全部模型都是 **VLM 把 bbox 当文本坐标 token 自回归输出，无专门检测头**（Qwen2.5/3-VL §2 架构；TreeVGR/Vision-R1/Orsta 继承 Qwen 文本坐标）。坐标与答案共用同一 LM 头，无独立空间回归分支。

**梯度路径错配**：
- 判别/VQA 由 next-token 交叉熵 + 答案正确性奖励在海量数据上优化，信号强、覆盖广；
- 坐标 token 在 LM 损失下只是普通 token，"物体对但框粗"在 token 级几乎不受罚；
- 而 RL 的 IoU 奖励**只在超阈值时给正梯度**（Vision-R1 式6 IoU≥ξ0 才平均；Orsta 式3 IoU<ε 直接给0；TreeVGR dual-IoU），阈值以下的粗框拿不到"收紧"梯度。
→ "知道在不在/哪一类"（判别）与"把紧框压到正确区域"（定位）两条能力不共享有效梯度，故 P(定位对|判别对)=0.35、φ=0.12 近乎独立。

**两个解耦极端（论文机制解释）：**
- **TreeVGR**（判别0.99/mIoU 0.281）：`grounding-then-answer` 范式把框当"为答对服务的中间证据"，答案奖励 R_acc 主导、IoU 只是 shaping；且该范式训练模型"对任何问题先吐一个 ROI 框"——负样本也照吐看似合理的证据框，直接解释 FG@Neg 75.6%。
- **Qwen3-VL**（判别最强82.8%/mIoU最低0.055）：相比 Qwen2.5-VL 做了两处**使定位变差**的改动——坐标系从绝对像素改为归一化[0,1000]（§3.2.4），空间/关系数据改为"相对其它物体表达而非绝对坐标"（§3.2.5），再加纯文本蒸馏/reweighting 倾斜文本推理。被优化成"强判别+定性空间推理"，牺牲逐像素回归。（注：归一化坐标可能与我们评测的像素 GT 坐标空间不一致，放大 IoU=0，需在 harness 排查——诚实标注的潜在混杂因素。）

**Qwen2.5-VL 为何均衡**（判别0.79/mIoU0.467，也是我们 verifier 骨干）：坚持**绝对像素坐标**训练（§2.1.2/§2.2.1）+ 专门合成"不存在类别"负样本 + 万类开放词表检测。它的绝对坐标基底正是"定位没塌"的原因；RL 变体的塌陷多来自在其之上叠加的奖励/冻结策略。

## 论点 3：为什么 BOH 好抓、ROH 难抓（贯通 cheap-signal 结论）

- **BOH = 一阶存在性/类别判别**：由被重度优化的识别/VQA 通路承担（Qwen2.5-VL 有"不存在类别"负样本 §2.2.1；Qwen3-VL discrimination-focused 训练 §3.2.2）。所以即使定位塌陷，"在不在/是不是"这一维度信号充足 → 检测器/verifier 抓得到（cheap AUROC 0.63–0.66）。
- **ROH = 物体都在场，只有关系/属性/角色绑定错**：所有存在性/前景/类别检查全通过，唯一错的是绑定；而**没有一个模型的奖励或架构学过"关系不成立就该拒绝"**（IoU 只惩罚空间不重叠，不惩罚语义绑定不成立）。检测器一阶信号对 ROH 近乎盲视（cheap AUROC 0.51–0.55）。
- **CoT 不救场**：推理链只被最终 IoU 奖励优化，不被"推理是否忠实于关系"优化 → 模型为"最显著候选"编造合理化解释（Seg-zero Fig.7 "the RV is the most suitable"、UniVG-R1 Fig.4 "the closest match"）。推理在为定位背书，不是核验绑定。

**Orsta 为何跨所有 verifier 方法最难判别**（AUROC 塌到 0.56、需集成救）：V-Triune 多任务统一 RL 用极严 Dynamic IoU（0.85→0.95→0.99）+ format 强制，把模型逼成"总是自信吐一个格式规整、看似精确的框"，幻觉框与正确框在置信度/格式/几何规整度上**趋同**、失去可分特征；且 §4.6 为止梯度爆炸冻结 ViT+connector，定位被训成"脱离视觉核查的 LLM 端生成习惯"。这是 Orsta 幻觉"看起来最像真的"的机理根源。

## 论文用途（对 V-SIGHT 叙事的加固）
1. **贡献一升级为机制论点**：ROH>BOH 与 VQA↔grounding 解耦不是偶然现象，是"正样本-only RL + 坐标 token 无独立梯度"两个训练范式选择的必然产物。Visual-RFT 的剂量-反应反例提供近似因果证据。
2. **verifier 的解法层次正确**：tradeoff 在训练范式层面，逐个重训上游不现实 → 即插即用后处理 verifier 是对的层次。
3. **BOH/ROH 分层设计有据**：BOH 靠一阶存在性信号（便宜头/检测器）即可；ROH 无任何上游监督覆盖，必须外部 VLM 级语义验证——直接支撑分层触发架构。
