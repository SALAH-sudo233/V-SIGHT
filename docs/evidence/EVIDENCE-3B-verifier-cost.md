# 证据资产：3B VLM verifier — ROH 判别力有多少来自规模（成本砍半验证）

> 问题：ROH 必须用 VLM（便宜信号做不到，AUROC~0.55）。但一定要 7B 吗？换 3B+LoRA 保住多少 ROH 判别力？
> **结论：3B 保住 7B ~90% 的 ROH AUROC，且远超便宜检测器头。ROH 判别力主要来自"VLM 级语义推理"这个能力层级，
> 不是 7B 规模本身——verifier 骨干可砍到 3B，成本近半。**

方法：同样弱标签、同一训练数据、同一推理契约，把 B1b 的骨干从 Qwen2.5-VL-7B 换成 3B，500-dev 上同口径 eval。
脚本同 `b1b_train_lora.py --model <3B>` / `b1b_eval.py --base <3B>`。

## 三方对比：correct-vs-halluc separation AUROC（BOH / ROH）

| 上游模型 | 便宜检测器头 | **3B VLM LoRA** | 7B VLM LoRA | 3B/7B ROH 保留率 |
|---|---|---|---|---|
| LENS | 0.706 / 0.585 | **0.806 / 0.679** | 0.855 / 0.739 | 92% |
| Seg-zero | 0.710 / 0.579 | **0.778 / 0.652** | 0.844 / 0.725 | 90% |
| Orsta-7B | 0.276 / 0.231 | 0.605 / 0.583 | 0.565 / 0.553 | — |
| Qwen3-VL | (n=12 噪) | 0.735 / 0.713 | 0.863 / 0.833 | — |

（主力上游 LENS/Seg-zero 统计稳，nCorr 248/275）

## 关键读法
1. **3B 保住 7B ~90% 的 ROH 判别力**（LENS ROH 0.679 vs 0.739、Seg-zero 0.652 vs 0.725），BOH 同样保住 ~92%。
2. **3B ROH（0.65–0.68）远超便宜头（0.55）**：再次坐实"ROH 需要 VLM 级推理"，但 3B 这个层级已足够——**不是 7B 规模的功劳，是 VLM 语义推理能力层级的功劳**。
3. **Orsta 上 3B 反而略好于 7B**（0.583 vs 0.553）——Orsta 是所有方法都最难的上游，两者都近随机，差异在噪声内，不改变"Orsta 是能力边界"的结论。

## 对成本护城河的意义（回应"单次预算"质疑）
- verifier 骨干可从 7B 砍到 3B，**推理成本近半**，ROH 能力仅损失 ~10%。
- 结合便宜信号侦察，形成清晰的**分层成本设计**：
  - BOH：便宜检测器头（0.71，1 次检测器前向，~0.12s）先过滤；
  - ROH/不确定：升级到 3B VLM（0.65–0.68），而非 7B。
- 论文口径：诚实报告"一次额外 VLM 验证"，但用 3B 把这次验证的成本压到最低；并可报告分层触发下的平均 VLM 调用率。

## 边界
- 3B 单 epoch、r=8、未调超参，可能还有上探空间。
- Qwen3-VL/Orsta 样本少或本身难，主结论以 LENS/Seg-zero 为准。
- 弱标签（IoU/存在性）；ROH 的因果 edge 正确性仍需 S4。
