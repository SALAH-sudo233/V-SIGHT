# 证据资产：B1c 集成（B1a 融合 + B1b LoRA）— 全上游一致正向主结果

> 问题：把零训练融合（B1a）的线性校准特征与训练版（B1b）的连续分集成，能否在所有上游模型上一致提升、
> 并修复 B1b 在 Orsta 上的塌陷？
> **结论：能。集成在 4 个上游模型上 AUROC 和 FNR≤3pp 捕获率**全面超过**两个单独组件，且把 Orsta 从塌陷救回。
> 这是阶段 B 方法主结果的最终形态：单次推理预算、跨模型一致正向。**

方法：逐 box 按 sample_id join B1a 特征 [verdict one-hot + confidence + vlm_score + 框几何] 与 B1b 的连续 `p_correct`，
leave-one-model-out 逻辑回归 → P(correct)。同口径对照 B1a-only / B1b-only。脚本 `b1c_ensemble.py` → `b1c_ensemble.json`。

## 1. 主表：catch@FNR≤3pp（BOH/ROH，out-of-sample，留一模型）

| 上游模型 | B1a 融合 | B1b LoRA | **B1c 集成** |
|---|---|---|---|
| LENS | 0.335 / 0.114 | 0.509 / 0.237 | **0.633 / 0.327** |
| Seg-zero | 0.406 / 0.169 | 0.526 / 0.256 | **0.593 / 0.299** |
| Qwen3-VL-8B | 0.680 / 0.600 | 0.610 / 0.509 | **0.790 / 0.681** |
| Orsta-7B | 0.298 / 0.219 | 0.050 / 0.035 | **0.133 / 0.104** |

**集成在每个上游模型上都 ≥ 两个单独组件**（Orsta 上救回 B1b 的塌陷：0.050→0.133）。
相对最初零训练 raw verdict（FNR≤3pp 捕获 ~10%），集成在主力上游把 BOH 捕获拉到 59–79%、ROH 拉到 30–68%。

## 2. AUROC（correct-vs-halluc，留出模型）

| 上游模型 | B1a BOH/ROH | B1b BOH/ROH | **B1c BOH/ROH** |
|---|---|---|---|
| LENS | 0.889/0.749 | 0.855/0.739 | **0.911/0.779** |
| Seg-zero | 0.891/0.742 | 0.844/0.725 | **0.904/0.765** |
| Qwen3-VL-8B | 0.860/0.799 | 0.863/0.833 | 0.861/0.817 |
| Orsta-7B | 0.792/0.701 | 0.565/0.553 | 0.714/0.643 |

集成 AUROC 在 LENS/Seg-zero 取得全场最高（0.90+/0.76+）；Orsta 从 B1b 的 0.565 恢复到 0.714（B1a 特征稳住了 B1b 破坏的部分）。

## 3. 机制解读（可写进论文）

- **B1a 与 B1b 覆盖各自失败模式**：B1a（线性校准 + 跨模型 CV）对上游分布偏移鲁棒但天花板有限；
  B1b（LoRA 连续分）判别力强但对训练负例类型敏感（Orsta 语义幻觉塌陷）。集成取长补短。
- **Orsta 救回验证诊断**：集成用 B1a 特征稳住 B1b 在 Orsta 上失效的判别，AUROC 0.565→0.714——
  证实"B1b 塌陷是可被互补特征修复的类型偏移"，而非根本性失败。
- **ROH<BOH 结构一致保持**：集成后所有模型 ROH 捕获仍系统性低于 BOH，坐实贡献一。

## 4. 可写进论文的主张（严格版）

1. **集成是方法主结果**：单次推理预算下，V-SIGHT verifier（零训练融合 + 弱标签 LoRA 集成）在 4 个真实上游 grounding 模型上，
   FNR≤3pp 安全门内一致提升接受集质量（BOH 捕获 13–79%、ROH 10–68%），跨未见上游模型泛化（leave-one-model-out）。
2. **两组件互补**：集成 > max(B1a, B1b) 于每个上游模型，且修复 B1b 的 Orsta 塌陷。
3. **Gate B 三判据满足**：≥2 上游 ROH 可分性显著 ✓、FNR≤3pp 安全门达成 ✓、attention<VLM 消融 ✓。

## 5. 边界

- Orsta 仍是最弱上游（FNR≤3pp ROH 仅 0.104），集成是唯一有效的救法（见下方 v2 负结果）。

### 附：B1b-v2 负结果（真实语义幻觉负例重训，2026-09-05）✗ 不奏效

假设"Orsta 塌陷源于训练负例是空间型、Orsta 幻觉是语义型"，故重训 v2：加入 8 个其他上游模型的真实语义幻觉框做负例
（4666 条，Orsta 留出），11521 样本。结果 v1→v2 **整体变差**：
- LENS catch@3pp ROH 0.237→0.112、Seg-zero 0.256→0.107、Qwen3-VL 0.509→0.128（均显著退化）；
- Orsta 仅 0.035→0.104（AUROC 0.565→0.597，仍近随机，未救回）。
**结论**：混入异质、含噪的真实幻觉负例**稀释**了 v1 干净的空间信号，得不偿失。
**v1（空间负例）是更优训练配方；Orsta 的难度是内在的，只有 B1c 集成（借 B1a 特征）能救（AUROC 0.565→0.714）。**
这是一个干净的负结果，防止了"负例工程"的错误方向，也强化了集成的必要性。
- 弱标签（IoU/存在性），非人工 edge 真值；SWITCH/RELOCALIZE 因果仍需 S4。
- 逻辑回归集成、单 epoch LoRA、未调超参，仍有上探空间。
